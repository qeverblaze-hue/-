# 一口接一口 · 贪吃蛇

一个无需第三方依赖的网页版贪吃蛇，支持键盘、触屏、三档速度、暂停恢复、重新开始，以及当前浏览器中的最高分记录。

## 运行

需要 Node.js 20 或更新版本。在仓库目录执行：

```sh
npm start
```

默认端口为 3000，可用 `PORT` 环境变量更改。请通过 HTTP 服务打开页面；游戏使用 ES 模块，不支持直接以 `file://` 打开 HTML。

## 操作

- 方向键或 W / A / S / D：移动。
- 空格：开始、暂停或继续。R：重新开始。
- 手机：滑动棋盘，或使用屏幕方向按钮。
- 每颗果实得 10 分；撞墙或身体结束游戏，填满棋盘获胜。
- 开局前或暂停时可调整速度；切换标签页自动暂停。

## 验证

```sh
npm test
```

测试使用 Node.js 内置测试工具。页面使用原生 HTML、CSS、JavaScript 与 Canvas，没有构建步骤或外部资源。

`game.js` 包含游戏逻辑，`app.js` 负责交互与绘制，`server.js` 提供本地静态文件服务。

## 发布到 GitHub Pages

将游戏文件上传到 GitHub 仓库的 `main` 分支后，在仓库的 **Settings → Pages** 中：

1. 将 **Source** 设为 **Deploy from a branch**。
2. 选择 **main** 分支及 **/(root)** 目录，点击 **Save**。
3. 等待部署成功，再打开 Pages 设置页面显示的网站地址。

此项目使用相对资源路径，支持仓库子路径。GitHub Pages 直接提供静态文件，不需要运行 `npm start` 或安装 Node.js。`.nojekyll` 用于跳过 Jekyll 处理。以上是部署步骤，不表示仓库已经上传或网站已经发布。
